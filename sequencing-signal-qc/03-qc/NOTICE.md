# Sequencing signal QC sources and reuse

The processed feature tables come from the [MicrobIEM known-mixture benchmark](https://doi.org/10.1186/s12915-023-01737-5) and [NASA OSD-890](https://doi.org/10.26030/2q5v-by72). The MicrobIEM article data and NASA dataset use CC0. The MicrobIEM source repository uses GPL-3.0. [GPL-3.0 license](GPL-3.0.txt)

The starter contains normalized feature measurements and keeps the controls for each Rapid run separate. Use the tables to compare filtering decisions on the supplied mixtures.
