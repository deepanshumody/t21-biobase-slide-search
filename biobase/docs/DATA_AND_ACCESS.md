# Data access and repository contents

## Approved access route

The source data are the Biobase Find the Right Patients challenge packs supplied to confirmed hackathon teams.
The [event README](https://github.com/humic-labs/hackathon-2026-11-14-resources) directs Biobase teams to the sponsor onboarding process for access instructions.
Use that process rather than treating this repository as a data mirror.

## Included

- Project Python scripts and the pinned NumPy requirement.
- Derived C1 organ predictions, C2 baseline rankings, and validation records.
- The methodology PDF and experiment summaries.
- Hashes that identify the original source, input, and output artifacts.

## Excluded

- Raw slide images, thumbnails, and input metadata packs.
- Original tile and slide embedding files.
- Downloaded archives and pretrained model checkpoints.
- Large experimental feature caches.
- Credentials, access tokens, private access codes, and local environment files.

Derived records contain de-identified challenge slide IDs and organ labels.
Keep this project private and restrict access to Team T21, organizers, and assigned judges.
No general redistribution permission for Biobase data is asserted here.
The providers' model and data terms continue to apply independently of this repository.

## Review and submission responsibilities

The event requires a private repository with the judged work on `main` by 5 PM Pacific on November 14, 2026.
Obtain the organizers' and assigned judges' GitHub handles through the official event channel, grant appropriate access, and verify that they can open the README and report.
Submit the project once for Team T21 through the event form.
The Biobase prize's dedicated evaluation-question field must also be completed for that prize entry.
The repository preparation does not itself submit forms, send messages, or grant access.
